# Initial Handoff Prompt for Claude Code

זה הפרומפט הראשון שאתה (עוז) נותן ל-Claude Code אחרי שאתה מצביע אותו על תיקייה זו.

---

## העתק את הטקסט הבא ל-Claude Code

```
שלום קלוד.

אני עוז, יזם סולו ישראלי. אני בונה SaaS לרואי חשבון בישראל
שאוטומציית הזנת חשבוניות ספק לפריוריטי דרך פורמט MOVEIN.DAT
של חשבשבת.

הקובץ CLAUDE.md בשורש התיקייה הוא ה-system prompt שלך — קרא 
אותו ראשון ולפי ההוראות שם.

אחרי שקראת CLAUDE.md, קרא בסדר הזה את 4 המסמכים:

1. README.md (root)              ← נווט בתיקייה
2. 01_executive/vision.md         ← מה המוצר ולמה
3. 04_architecture/strategic_spec.md  ← איך הוא בנוי
4. 06_implementation/phase_1_mvp.md   ← מה אנחנו בונים עכשיו

אל תכתוב קוד עד שתסיים את הקריאה. 

המשימה הראשונה שלך:

לאחר הקריאה, ענה על 4 הדברים הבאים בקצרה:

1. **סיכום ב-5 שורות**: מה המוצר, למי, ההבדל ממתחרים, ומה ה-MVP

2. **3 שאלות הכי חשובות שיש לך** לפני התחלת קוד. רק שאלות שחוסמות 
   באמת. אל תשאל שאלות שתשובות שלהן בתיקייה.

3. **הצעת מבנה תיקיות לקוד** (לא לאפיון — לקוד החדש שתכתוב). 
   האפיון נשאר ב-priority-cpa-automation-spec/. הקוד צריך תיקייה 
   אחרת או repo נפרד. תציע מבנה.

4. **המלצה על Lovable או React custom build** — איזה מוסיף עכשיו 
   ומדוע. החלטה זו פתוחה ב-decisions_log.md ואני רוצה שתביא נתונים.

אחרי שתענה על אלו, אני אאשר ואז תתחיל בקוד הראשון:
skill ה-movein-generator (TypeScript, מבוסס על poc-reference שב-
08_poc_artifacts/).

הנחיות מסכמות:
- TypeScript בלבד
- Test-driven (vitest)
- Multi-tenant מהיום הראשון (company_id בכל interface)
- שמור על אותו canonical JSON schema שראית ב-08_poc_artifacts/invoice_examples/
- אל תקפוץ ל-Phase 2

קח את הזמן. אל תמהר. הבנה > מהירות.
```

## תגובה מצופה מ-Claude Code

הוא צריך:

1. ✓ לקרוא את CLAUDE.md ולציית להנחיות שם
2. ✓ לקרוא את 4 המסמכים
3. ✓ להציג סיכום 5 שורות
4. ✓ 3 שאלות ממוקדות (לא שאלות בסיסיות)
5. ✓ הצעת מבנה תיקיות לקוד
6. ✓ המלצה Lovable vs React עם נימוק

## אם Claude קופץ קדימה ומתחיל לקודד

עצור אותו:
```
עצור. לא ביקשתי קוד עדיין. תחזור ל-4 הסעיפים שביקשתי ותשלים אותם 
לפני שתכתוב שורת קוד.
```

## אחרי שקלוד עונה

### אם התשובות טובות
תאשר ותגיד:
```
מצוין. אישור על מבנה התיקיות (או תיקונים). מתחיל ב-skill 
movein-generator. קרא קודם 08_poc_artifacts/generate_movein.py ו-
05_domain/movein_format_spec.md, אז התחל בכתיבה.
```

### אם התשובות חלקיות
:
```
תשובה X לא מספקת. תשפר אותה לפי הנתונים שב-[קובץ ספציפי].
```

## למה זה חשוב להתחיל ככה

ה-prompt הזה דואג ל-3 דברים:

1. **קלוד מבין את הקונטקסט המלא** לפני קוד — חוסך 10x עבודה אחר כך
2. **נשארת בשליטה** — הוא לא קופץ למבנה שגוי
3. **מבנה הקוד מוסכם מראש** — לא תצטרך לעשות refactor אחרי 1000 שורות
