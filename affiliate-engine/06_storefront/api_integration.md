# API Integration — AliExpress Affiliate

**מימוש**: `packages/skills/aliexpress-api`
**סטטוס**: הצנרת בנויה ונבדקת. **טרם רצה מול הגייטוויי האמיתי** — אין עדיין מפתחות.

---

## מה נדרש מעוז

| פריט | מאיפה | מתי |
|---|---|---|
| `app_key` + `app_secret` | הרשמה כמפתח בפורטל השותפים | ימים עד שבועות |
| `tracking_id` | נוצר בחשבון השותף | מיידי אחרי אישור |
| שם פרמטר ה-SubID | **קריאה מלינק אמיתי שנוצר בפורטל** | חוסם תנועה |

השלושה נשמרים ב-Supabase Vault. `networks.vault_secret_name` מחזיק הפניה בלבד — **אף פעם לא את הסוד עצמו ב-DB או בקוד**.

---

## חתימת בקשה

הגייטוויי משתמש בסכמת TOP הקלאסית: מיון כל הפרמטרים לפי מפתח, שרשור מפתח+ערך ללא מפריד, וחתימה על התוצאה.

```
base = sort(params).map(k => k + params[k]).join('')
sha256:  HMAC_SHA256(base, secret).hex().toUpperCase()
md5:     MD5(secret + base + secret).hex().toUpperCase()
```

**שתי הסכמות ממומשות בכוונה.** אפליקציה שהוקצתה לאחת נכשלת מול השנייה עם שגיאת "חתימה שגויה" חסרת פירוט — היכולת להחליף היא הדרך המהירה ביותר לאבחן מה קיבלת.

חותמת הזמן היא epoch במילישניות. **השעון מוזרק** (`now: () => number`) ולא נקרא בתוך הקוד, כדי שחתימה תהיה ניתנת לשחזור בטסט.

## שתי מלכודות שכבר מטופלות בקוד

**1. שגיאה בתוך HTTP 200.** הגייטוויי מחזיר 200 גם לכישלון, ועוטף אותו ב-`error_response`. קוד שבודק סטטוס HTTP בלבד יקרא שגיאה כהצלחה ויכתוב קטלוג ריק ל-DB. `unwrap()` חופר את השגיאה מתוך הגוף.

**2. שני ערוצי כישלון.** מעבר ל-`error_response` יש `resp_result.resp_code` עצמאי. שניהם נבדקים.

**3. תוצאה יחידה מגיעה כאובייקט ולא כמערך.** דף עם מוצר אחד מחזיר `products.product` כאובייקט. `asArray()` מטפל בשניהם — בלי זה `.map` קורס על העמוד הצר ביותר בקטלוג.

## שגיאות ו-retry

`isRetryable()` מבחין בין חסימת קצב זמנית לתקלה קבועה. **מפתח שגוי ייכשל זהה בכל ניסיון** — retry עליו רק מעכב את הרגע שבו מישהו קורא את השגיאה.

חסימת קצב היא הכשל הצפוי בסנכרון: 300 עמודים × מספר שאילתות לעמוד. הסנכרון מריץ בהדרגה ולא בבת אחת.

## פיתוח בלי מפתחות

```ts
import { createAliExpressClient, createMockTransport } from '@affiliate/aliexpress-api';

const client = createAliExpressClient({
  appKey: 'dev', appSecret: 'dev', trackingId: 'ostech',
  now: () => Date.now(),
  transport: createMockTransport(),   // ← החלפה יחידה לפרודקשן
});
```

ה-fixtures כוללים בכוונה את המקרים המעצבנים: תוצאה יחידה כאובייקט, מחירים כמחרוזות, עמלה עם ובלי `%`, וחנות מתחת לסף האיכות — כדי שלמסננים יהיה מה לדחות.

**ההשלכה**: כל הצנרת — נירמול, סינון, דירוג, בניית עמודים, SEO — נבנית ונבדקת היום. כשהמפתחות מגיעים, מחליפים שורה אחת.
