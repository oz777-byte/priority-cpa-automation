# Phase 1 — MVP

**מטרה**: לולאה סגורה מלאה — לינק → קליק → המרה → EPC → החלטה — על נכס תוכן אמיתי אחד לפחות.

> **הקשר**: ה-MVP מורץ במקביל לספרינט האימות (`validation_sprint.md`), שבו הנישה היא מרקטפלייס מוצרים מוחשיים. הספרינט מספק את הנתונים האמיתיים הראשונים ש-M4 ו-M5 צריכים.
**משך מוערך**: 3-5 שבועות בקצב של 15-20 שעות/חודש (כלומר: ריאלית 2-3 חודשי קלנדר).
**Definition of Done**: עוז מייבא דוח עמלות אמיתי, והמערכת אומרת נכון איזה עמוד ייצר אותו.

## סדר עבודה מומלץ

M2 → M3 → M4 → M5. **לא לעבוד במקביל.** M3 בלי M2 חסר משמעות, ו-M5 בלי M4 מציג אפסים.

**במקביל למסלול הטכני** (לא חוסם קוד):
1. פתיחת חשבונות ברשתות — לוקח 1-2 שבועות אישור
2. רכישת דומיין
3. פגישה עם רו"ח על מסלול מס
4. כתיבת 3 נכסי התוכן הראשונים
