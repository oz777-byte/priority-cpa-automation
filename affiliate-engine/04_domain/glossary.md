# Glossary — מונחי אפילייט

מונחים באנגלית (כך הם מופיעים בקוד ובדוחות הרשתות), הסבר בעברית.

---

## שחקנים

| מונח | הסבר |
|---|---|
| **Advertiser / Merchant** | המפרסם — בעל המוצר שמשלם עמלה |
| **Publisher / Affiliate** | המפרסם-שותף — אנחנו |
| **Network** | מתווך שמנהל תוכניות, מעקב ותשלומים (Impact, CJ) |
| **Program / Offer** | תוכנית שותפים ספציפית של מפרסם אחד |

---

## מדידה

| מונח | נוסחה / הסבר |
|---|---|
| **Click** | הקלקה על לינק שותף — יחידת המדידה הבסיסית |
| **Impression** | הצגה של הלינק/באנר בלי קליק |
| **Conversion** | פעולה שמזכה בעמלה (רכישה, ליד, הרשמה) |
| **CR — Conversion Rate** | `conversions / clicks` |
| **EPC — Earnings Per Click** | `revenue / clicks` — **המדד המרכזי במערכת** |
| **RPM** | `(revenue / pageviews) × 1000` — הכנסה לאלף צפיות |
| **AOV** | Average Order Value — שווי הזמנה ממוצע |
| **Reversal / Chargeback** | ביטול המרה — החזר, הונאה, לקוח שלא שילם |
| **Approval Rate** | `approved / total_conversions` — קריטי: EPC לפני אישור הוא פיקציה |

---

## מעקב

| מונח | הסבר |
|---|---|
| **Tracking Link** | URL ייעודי שמזהה את השותף שהביא את הקליק |
| **SubID** | פרמטר חופשי שאנחנו שולטים בו — **הליבה של המערכת** (`tracking_and_attribution.md`) |
| **Cookie Window** | חלון הייחוס — כמה ימים אחרי קליק ההמרה עדיין שלנו |
| **Postback / S2S** | Server-to-Server — הרשת מודיעה לשרת שלנו על המרה, בלי תלות בקוקי |
| **Pixel** | תג JS בעמוד תודה שמדווח המרה — פחות אמין (חוסמי פרסומות, ITP) |
| **Deep Link** | לינק שותף שמוביל לעמוד מוצר פנימי ולא לדף הבית |
| **Link Cloaking** | הסתרת ה-URL הגולמי מאחורי דומיין משלנו (`/go/tool-name`) |
| **Last Click Attribution** | הקליק האחרון לפני ההמרה מקבל את הקרדיט — התקן בתעשייה |

---

## כספים

| מונח | הסבר |
|---|---|
| **CPA** | Cost Per Action — סכום קבוע לכל המרה |
| **CPL** | Cost Per Lead — תשלום לליד |
| **RevShare** | אחוז מהמכירה |
| **Recurring Commission** | עמלה שחוזרת בכל חידוש מנוי — **היעד** |
| **Payment Threshold** | סף מינימלי לתשלום (לרוב $50-100) |
| **NET-30 / NET-60** | תנאי תשלום — כמה ימים אחרי סוף החודש משלמים |
| **Locking Period** | תקופה שבה ההמרה "ננעלת" לפני שהיא ניתנת למשיכה |

---

## תוכן ותנועה

| מונח | הסבר |
|---|---|
| **Asset** | נכס תוכן — עמוד, פוסט, סרטון, ניוזלטר. **יחידת המדידה שלנו** |
| **Placement** | מיקום הלינק בתוך הנכס (hero, comparison-table, footer) |
| **Buyer Intent** | כוונת קנייה של מילת המפתח: informational → commercial → transactional |
| **SERP** | דף תוצאות החיפוש |
| **E-E-A-T** | Experience, Expertise, Authoritativeness, Trust — קריטריון האיכות של גוגל |
| **Money Page** | עמוד שנועד להמיר (השוואה, ביקורת) בניגוד לעמוד מידע |

---

## ראשי תיבות במערכת

| קיצור | מלא |
|---|---|
| `asset_id` | מזהה נכס תוכן |
| `offer_id` | מזהה תוכנית שותפים |
| `subid` | מחרוזת ה-attribution המקודדת |
| `TimeROI` | הכנסה מצטברת חלקי שעות שהושקעו — המדד המנהל |
